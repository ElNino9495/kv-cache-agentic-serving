31 pauses, 42.5 teacher-forced steps per pause on average (cap 64). dNLL in nats per target token against the per-step bf16 row. Base: int2 history, block 16; block 0, the recent 64 tokens and the trailing partial block are bf16. Tool output prefilled over the int2 history with a per-chunk top-128 fetch (fetch rows; the uniform int2 row and fetch_all_noprefill without); uniform rows over their own precision, the bf16 row over bf16.

## Checks

- bf16 row vs itself: max |dNLL| 0.0e+00
- per-step vs sdpa teacher forcing, NLL difference per pause (the stop criterion): bf16 row max 0.0084 (mean 0.0032), int2 row max 0.0194 (mean 0.0043)
- uniform int2 dNLL, sdpa batched +0.0310 vs per-step +0.0310 (max per-pause |difference| 0.0141)
- largest single-token log-prob difference (reported only): bf16 0.201, int2 0.382
- 79.7 s per pause on average, 41.2 min total
- speculative token (spec rows, guess of each step's input from the real previous token): correct on 81.9% (spec@16), 82.0% (spec@32), 81.7% (spec@64), 81.8% (spec@128), 82.4% (spec@match) of steps
- speculative token (spec_chain rows, SpeCache's chained guess of the next input): correct on 37.4% (spec_chain@16), 36.4% (spec_chain@32), 39.7% (spec_chain@64), 36.2% (spec_chain@128), 36.5% (spec_chain@match) of steps
- k = match: 1,116 tokens per KV head and layer on average (min 495, max 2,110), i.e. int2 + fetched set = int3's memory
- GPU memory: measured peak 38.7 GB (allocated by PyTorch), estimated 37.1 GB
